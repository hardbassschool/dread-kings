# Dread Kings C++ Reference Layer

Dread Kings treats cppreference as a navigable reference layer, not as a substitute for the ISO C++ standard.

Primary reference: https://en.cppreference.com/w/cpp/
Compiler support: https://en.cppreference.com/cpp/compiler_support
C++23 support: https://en.cppreference.com/cpp/compiler_support/23

The implementation is intentionally built against standard C++ facilities and records the selected language level in the build system. A future knowledge index can map symbols, feature-test macros, headers, and compiler support entries to generated Dread King actions.
